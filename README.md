# Le Decision

Eine kleine Web-App, die dir Entscheidungen abnimmt.

- **Zufall:** eine Option per Spielautomat auslosen oder eine Zufallsrangliste erstellen
- **Turnier:** Optionen treten paarweise gegeneinander an, bis ein Sieger feststeht (mit Freilosen bei ungerader Anzahl)
- **Kategorien** mit eigenen Listen und Vorschlägen, die automatisch dazulernen
- **Tippfehler- und Sprachtoleranz** (z. B. „idnisch“ oder „Indian“ → „Indisch“)
- Hell- und Dunkelmodus

Alles läuft im Browser, ohne Konto und ohne Server. Kategorien und Vorschläge werden nur lokal im jeweiligen Browser gespeichert.

Live: https://oluwatoyinballer-dev.github.io/LeDecision/
